САЙТ ДЛЯ АНЕЛЬ — инструкция для новичка
=======================================

Файлы:
- index.html — весь сайт: дизайн, анимации и интерактивность уже внутри.

КАК ОТКРЫТЬ НА КОМПЬЮТЕРЕ
1. Распакуй архив.
2. Открой папку и дважды нажми на index.html.
3. Сайт откроется в браузере. Для включения музыки нажми кнопку «Включить музыку» — браузер разрешает звук только после нажатия.

КАК ПЕРСОНАЛИЗИРОВАТЬ
- Открой index.html в Блокноте или любом редакторе кода.
- Найди текст поздравления в секции id="letter" и замени его на свой.
- Фотографии можно выбрать на самом сайте в блоке «Маленькая галерея». Они показываются только в текущем открытом сеансе и не отправляются в интернет.
- Можно изменить подпись «твой человек» на своё имя или прозвище.

КАК БЕСПЛАТНО ОПУБЛИКОВАТЬ САЙТ ПО ССЫЛКЕ (GitHub Pages)
1. Зарегистрируйся или войди на https://github.com/
2. Создай новый репозиторий, например anel-birthday, и выбери Public.
3. Нажми Add file → Upload files и загрузи index.html из этой папки.
4. Нажми Commit changes.
5. Открой Settings → Pages.
6. В разделе Build and deployment выбери Deploy from a branch.
7. В Branch выбери main и папку /(root), затем Save.
8. Подожди несколько минут. GitHub покажет адрес примерно такого вида:
   https://ТВОЙ-ЛОГИН.github.io/anel-birthday/
9. Открой ссылку на телефоне и проверь сайт. Отправь ссылку Анель.

ВАЖНО
- Сайт не отправляет данные и не требует сервера.
- Фото, которые выбираются в галерее, локальные: они не встраиваются в опубликованную страницу и не видны другому человеку. Чтобы добавить фото, видимые Анель по ссылке, положи изображения в репозиторий и замени соответствующие photo-slot на img с путём к файлу, например src="photos/our-photo.jpg".
- Музыка создаётся браузером из простых нот, без сторонних аудиофайлов. Это специально сделано, чтобы сайт работал сразу и не зависел от авторских музыкальных файлов.
- Шрифт загружается из Google Fonts, но при отсутствии интернета сайт использует системный шрифт.
